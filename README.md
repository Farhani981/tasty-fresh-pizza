# Tasty & Fresh Pizza Website

A modern, responsive website for Tasty & Fresh Pizza, showcasing our delicious pizzas and premium ingredients.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Smooth Scrolling**: Seamless navigation between sections
- **Interactive Menu**: Hover effects and mobile-friendly navigation
- **Premium Ingredients**: Highlighting our quality ingredients
- **Popular Pizzas**: Showcase of our best-selling pizzas with ratings
- **Contact Information**: Easy access to services, delivery areas, and social media

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (ES6)
- Boxicons for icons
- Google Fonts (Raleway and Reddit Sans)

## How to Run

1. Clone or download the project files
2. Open `pizza.html` in your web browser, or
3. Use a local server (recommended for better functionality):
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000/pizza.html`

## Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge

## Customization

- **Colors**: Modify CSS custom properties in `:root`
- **Fonts**: Change font families in the Google Fonts link
- **Content**: Update text and images in `pizza.html`
- **Styling**: Adjust styles in `css/pizza.css`
